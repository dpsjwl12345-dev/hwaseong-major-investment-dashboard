# 부서별 현황 공통 화면

관광진흥과에서 확정한 구조를 7개 부서가 공유한다. 자세한 예산표와 사업 내용은 사업별 화면에 두고, 부서 화면에서는 위치와 추진단계를 확인한다.

## 공통 구성

- 부서명과 상징 아이콘, 부서별 짧은 타이포 문구.
- KPI 4개: 관리사업, 총사업비, 2027년 요구액, 누적 투자액. 기존 계산 함수를 그대로 사용하고 화면 표시만 억원 소수점 절사.
- 왼쪽 화성시 지도 / 오른쪽 사업 검색·목록. 사업명, 단계, 진척 막대, 상세 이동 화살표 유지.
- 파란 사업 핀, 오른쪽 아래에 겹친 번호. 번호는 해당 부서 목록 순서와 일치.
- 핀 선택 시 지도 확대 및 목록 즉시 스크롤. 목록 선택 시 해당 핀 선택. 지도 선택은 검색·권역 필터 해제.
- 기존 관리자 편집표는 ‘관리표 편집’ 전환으로 유지. 이 버튼은 기존 isAdmin 판정을 그대로 따른다.
- PC 지도·목록 병렬, 태블릿 폭 조정, 좁은 화면 세로 배치. 모션 감소 설정 존중.

## 부서별 표현

| 부서 | 상징·오브젝트 | 보조 색 |
|---|---|---|
| 문화예술과 | 팔레트·공연장 아이콘, 문화시설 매스 | 라벤더 |
| 문화유산과 | 유산 아이콘, 전통 지붕·기둥 매스 | 석재·황토 |
| 독립기념관 | 깃발, 기념탑 | 세이지 |
| 도서관정책과 | 책, 양쪽 서가를 연상시키는 건물 | 올리브 |
| 체육진흥과 | 체육·종목 아이콘, 운동장·경기장 | 청록 |
| 전국체전추진단 | 메달·경기장, 관중석과 운동장 | 스틸 블루 |
| 관광진흥과 | 기존 해안·섬·열차 등 개별 오브젝트 유지 | 웜 골드 |

기존 명소는 확인된 관광안내도 목록에서 관련된 범주만 표시한다. 도서관·체육시설 등의 기존 시설 위치는 아직 검증된 데이터가 없어 임의 추가하지 않는다. 가상 오브젝트는 사업 유형을 설명하는 기호이며 실제 설계도나 건축 형상이 아니다.

## 위치와 원형 보존

- 도시·구·읍면동 원형, 경계와 출처 표기는 기존 GIS 원본 그대로 유지.
- 관광진흥과는 기존 위치도 판독 대표좌표 유지.
- 다른 부서는 사업개요의 ‘사업위치’에 명시된 읍·면·동을 우선 사용한다. 없을 때 등록 district 값을 확인한다.
- 해당 읍면동의 대표점은 `hwaseong-map-metadata.json`의 행정경계 라벨 좌표다. 실제 사업지 좌표로 해석하지 않는다. 지도 하단에 이 차이를 표시하고, 확대도 읍면동 수준으로 제한한다.
- 입지가 ‘미정’이거나 인식할 위치 자료가 없으면 지도 핀을 만들지 않는다. 목록에는 ‘위치 미등록’으로 남는다. 여러 읍면동에 걸친 사업은 동일 번호로 각각 표시한다.
- 다음 단계는 사업별 위치도·주소에서 검증한 실제 좌표를 연결하는 것이다. 대표점을 실제 사업지라고 승격하지 않는다.

## 확인 경로

`/departments/culture`, `/heritage`, `/memorial`, `/libraries`, `/sports`, `/festival`, `/tourism` (각 경로는 `/departments/` 기준). 메인 메뉴에서도 동일 화면을 연다.
